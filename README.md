# University Zone

**한국외국어대학교 재학생을 위한 교내·주변 상권 정보 앱** (모바일 웹 프로토타입)

재학생 인증 기반으로 제휴 할인 혜택을 받고, 스탬프를 쌓고, 친구들의 방문 기록을 공유받는 서비스입니다.

---

## 서비스 구성

### 홈
- **스탬프 투어 배너** — 총학생회 주관 이벤트. 지정된 제휴 가게 5곳을 모두 방문하면 경품(스타벅스 기프티콘) 제공. 진행 현황을 배너에서 확인.
- **제휴 혜택 캐러셀** — 현재 이용 가능한 제휴 할인·서비스 목록을 가로 스크롤로 탐색.
- **인기 가게** — 리뷰 수·평점 기반 추천 가게 목록.

### 지도
- Leaflet 기반 지도에 제휴 가게 마커 표시.
- 상단 카테고리 필터(전체 / 카페 / 식당 / 주점 / 생활 / 제휴)로 마커 필터링.
- 마커 클릭 시 바텀시트에 가게 요약 정보 표시 → 가게 상세 페이지로 이동.
- 검색바로 가게 이름 검색 가능.

### 학교
- 교내 행사·이벤트 피드. 카테고리: 총학생회 / 단과대 / 주점 / 공연 / 동아리 / 학과.
- 각 행사별 날짜, 시간, 장소, 주관 단체 표시.
- 현재 등록된 행사 예시: 개강총회, 경영대 봄 주점, 동아리 박람회, 야간 영화제 등.

### 친구
- **활동 피드** — 친구들의 최근 방문·저장·리뷰 활동을 타임라인으로 확인.
- **친구 목록** — 친구별로 저장해둔 맛집 리스트와 개인 메모 열람 가능.

### 마이페이지
- 프로필: 이름, 학번, 학과, 재학생 인증 여부.
- **QR 코드** — 제휴 가게 방문 시 제시용 재학생 인증 QR.
- 내가 저장한 맛집 리스트 및 개인 메모.
- **단골 스탬프 카드** — 가게별 방문 누적 스탬프. 목표 달성 시 리워드(무료 음료, 할인권 등).

### 가게 상세
탭 구성: **홈 · 메뉴 · 리뷰 · 정보**
- **홈**: 대표 이미지, 별점, 제휴 배지, 혜택 요약, 영업시간.
- **메뉴**: 메뉴명·가격 목록.
- **리뷰**: 별점, 태그, 내용, 친구 리뷰 우선 노출.
- **정보**: 주소, 전화번호, 상세 영업시간.

## 핵심 개념

| 개념 | 설명 |
|---|---|
| **제휴 가게** | 총학생회와 협약을 맺은 가게. QR 또는 학생증 제시로 할인·서비스 혜택 제공. |
| **단골 스탬프** | 가게 방문 시 스탬프 적립. 목표 횟수 달성 시 리워드 지급. |
| **스탬프 투어** | 총학생회 주관 이벤트. 지정 가게 복수 방문 달성 시 경품 제공. |
| **친구 피드** | 동일 학교 인증 사용자들의 방문·저장·리뷰 활동 공유. |

## 가게 카테고리 및 등록 데이터

| 카테고리 | 등록 가게 |
|---|---|
| 식당 | 이문동 돈가스, 이문동 국밥, 회기 피자 & 파스타 |
| 카페 | 외대 카페 그린, 카페 모노 |
| 주점 | 회기 포차 |
| 생활 | 외대문구점, 이문 헬스짐 |

제휴 혜택 예시: 학생증 제시 10% 할인, QR 스캔 음료 500원 할인, 2인 이상 기본 안주 무료, 월회원 20% 할인 등.
